# Support

Start with [installation](installation.md) or [runtime and storage](runtime.md). For bugs and feature requests, use [GitHub Issues](https://github.com/Kook-Dohyun/To-Do-Connect/issues/new).

Include:

- Program and plugin version, OS and CPU architecture.
- MCP/AI client and affected provider.
- Reproduction steps, expected result and actual result.
- A redacted error message; for missing tools, which names are absent and where the inventory was checked.

Do not include passwords, tokens, OAuth client JSON, private tasks, credential caches or unredacted screenshots. Issues are public.

An installed package, server tool discovery and tools available in a conversation are separate checks. Updating a GitHub download does not automatically update a local installation or an account-uploaded plugin.

Support is provided by [Kook-Dohyun](https://github.com/Kook-Dohyun) on a best-effort basis. See [privacy](privacy.md) and [terms](terms.md).
